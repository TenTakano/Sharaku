---

## 概要

開発用データベースを削除してクリーンな状態にし、`npm run tauri dev` でアプリを起動する。

## 引数

なし

## 実行フロー

### 1. データの初期化

Bash ツールでコマンド `bash scripts/reset-dev-data.sh` を実行する（絶対パスや `~` パスは使わないこと）。

### 2. アプリの起動

Bash ツールで `npm run tauri dev` をバックグラウンド実行する（`run_in_background: true`）。

### 3. ユーザーへの報告

データの初期化が完了し、アプリを起動中であることを伝える。
