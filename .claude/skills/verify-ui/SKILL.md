## 概要

`scripts/screenshot.sh` を実行して Sharaku ウィンドウのスクリーンショットを撮影し、表示内容を確認する。

## 引数

なし

## 前提条件

- `pnpm run tauri dev` でアプリが起動していること
- Linux: `xdotool` と `imagemagick` がインストールされていること

## 実行フロー

### 1. スクリーンショットの撮影

Bash ツールで `scripts/screenshot.sh` を実行する。

### 2. 結果の確認

スクリプトの終了コードを確認する：

- **終了コード 0**: 成功。次のステップへ進む
- **終了コード 1**: ウィンドウが見つからない。アプリが起動しているか確認を促す
- **終了コード 2**: 必要なツールが未インストール。エラーメッセージに従いインストールを案内する

### 3. スクリーンショットの分析

Read ツールで `tmp/screenshot.png` を読み込み、以下を確認する：

- ページが正常に表示されているか
- レイアウト崩れがないか
- 意図した変更が反映されているか

### 4. 結果の報告

確認結果をユーザーに報告する：

- **問題なし**: 確認した内容のサマリーを伝える
- **問題あり**: 具体的な問題点を説明し、修正案があれば提示する
