# Sharaku 仕様書 - インポート機能

## 1. 概要

インポートとは、フォルダを「作品」として DB に登録する処理。
2 つのインポート画面がある:

- **単一取り込み画面**: 1 つのフォルダを 1 つの作品としてインポート
- **一括取り込み画面**: 複数のフォルダをまとめてインポート

---

## 2. ドラッグ&ドロップによるインポート起動

ライブラリ画面（library ビュー）でのみ有効。
ドロップ時にオーバーレイ「ここにフォルダをドロップして取り込み」を表示する。

### パス正規化

ドロップされたパスがファイルの場合、親ディレクトリに変換する。ディレクトリの場合はそのまま使用する。

### 分岐条件

ドロップされたパス数とフォルダ構造により、3 パターンに分岐する。

**パターン 1: 複数パス同時ドロップ**（paths.length > 1）

- 全パスを並列で正規化し、重複を除去（Set）
- 一括取り込み画面へ遷移（ドロップパスモード）

**パターン 2: 単一パス + サブフォルダに画像あり**

- パスを正規化後、サブフォルダ内の画像有無を判定
- サブフォルダ判定: 対象ディレクトリのサブフォルダ（min_depth=1）を再帰的に走査し、直下に画像ファイルを持つサブフォルダが 1 つでもあれば true
- 一括取り込み画面へ遷移（ルートパスモード）

**パターン 3: 単一パス + サブフォルダに画像なし**

- 単一取り込み画面へ遷移

---

## 3. 単一取り込み画面

2 ステップ構成: フォルダ選択 → メタデータ入力。

### フォルダ選択

- ドラッグ&ドロップからの遷移時はスキップ（初期パスが設定済み）
- 手動時はファイルダイアログでフォルダを選択

### メタデータ自動抽出（フォルダ名パース）

フォルダ名から作者名とタイトルを自動抽出する。以下の優先順でマッチを試みる:

| 優先度 | パターン                       | artist | title          |
| ------ | ------------------------------ | ------ | -------------- |
| 1      | `[Artist] Title`               | Artist | Title          |
| 2      | `Artist - Title`               | Artist | Title          |
| 3      | デフォルト（上記に該当しない） | 空     | フォルダ名全体 |

### メタデータ入力フィールド

以下の 6 項目を入力できる。タイトルのみ必須。

| フィールド   | 必須   | 型       |
| ------------ | ------ | -------- |
| タイトル     | はい   | テキスト |
| アーティスト | いいえ | テキスト |
| 年           | いいえ | 数値     |
| ジャンル     | いいえ | テキスト |
| サークル     | いいえ | テキスト |
| 出典         | いいえ | テキスト |

### resource_mode による差異

**full モード**:

- コピー/移動の選択 UI を表示
- 配置先パスのプレビューを表示（ディレクトリテンプレート適用結果）
- メタデータ変更時に 300ms デバウンスでプレビューを更新

**metadata_only モード**:

- モード選択 UI なし
- 「元の場所に登録されます」と表示

## 4. 一括取り込み画面

2 ステップ構成: フォルダ探索 → レビュー。

### 起点

一括取り込み画面には 4 つの起点がある:

1. **ドラッグ&ドロップ（複数パス）** → ドロップパスモードで探索開始、レビューステップへ直行
2. **ドラッグ&ドロップ（単一パス、サブフォルダあり）** → ルートパスモードで探索開始、レビューステップへ直行
3. **サイドバーの「一括取り込み」** → フォルダ探索ステップから開始（フォルダ選択ダイアログ）
4. **設定画面の整合チェック** → 未登録フォルダ情報を直接レビューステップへ渡す（探索スキップ）

### フォルダ探索

探索モードは 2 種類ある:

- **ルートパスモード**: 単一のルートディレクトリから再帰走査
- **ドロップパスモード**: 複数のルートディレクトリを走査。重複パスの排除（seen_paths）

進捗通知:

- 探索中: 50 フォルダごとに「N フォルダを探索中...」を通知
- 完了時: 「M 件のフォルダを検出」

### リーフフォルダ抽出ロジック

探索で見つかった「画像を含むフォルダ」の中から、最下層のもの（リーフフォルダ）のみを作品候補とする。

**判定手順**:

1. 画像を直接含むフォルダを全て候補として収集（各フォルダの直下にある画像ファイル数をカウント、再帰なし）
2. 各候補フォルダの全祖先パスを記録（ルートまで遡る）
3. 祖先パス集合に含まれるフォルダ = 中間フォルダ → スキップ対象
4. 祖先パス集合に含まれないフォルダ = リーフフォルダ → 作品候補

**具体例**:

```
root/
  ├─ chapter1/
  │  └─ photo.jpg        ← リーフ（作品候補）
  ├─ chapter2/
  │  └─ photo.jpg        ← リーフ（作品候補）
  └─ cover.jpg           ← root はスキップ（中間フォルダ）
```

この例では chapter1, chapter2 が作品候補となる。root は chapter1, chapter2 の祖先であるため中間フォルダとしてスキップされる。

スキップされたフォルダは画像数とともにユーザーに通知される。

### レビューステップ

テーブル形式で検出フォルダを一覧表示する。

**テーブル列構成**:

| 列               | 概要                                           |
| ---------------- | ---------------------------------------------- |
| チェックボックス | インポート対象の選択/解除                      |
| フォルダ名       | 検出されたフォルダのパス                       |
| 画像数           | フォルダ内の画像ファイル数                     |
| タイトル         | 編集可能。フォルダ名パースの結果がデフォルト値 |
| アーティスト     | 編集可能。フォルダ名パースの結果がデフォルト値 |
| 状態             | 登録済み/未登録                                |

**選択状態のデフォルト**:

- 登録済みフォルダ: 「登録済み」と表示、デフォルトで未選択
- 未登録フォルダ: デフォルトで選択済み

**操作**:

- タイトル・アーティストはインライン編集可能
- 全選択/全解除チェックボックス
- full モード時: コピー/移動の選択

**制限事項**:

- 一括取り込みでは year, genre, circle, origin は入力不可（null で登録）

## 5. インポート実行

### キュー方式

インポートリクエストはキューに追加され、バックグラウンドワーカーが順次処理する。
UI はブロックされず、ユーザーは他の操作を継続できる。

### resource_mode による分岐

**metadata_only モード**:

- 元のフォルダパスをそのまま works.path に記録
- ファイル操作なし

**full モード**:

以下の手順で処理する:

1. ディレクトリテンプレートとメタデータからパスを生成
2. パス重複時は `_0001` 形式のサフィックスを付与して一意にする
3. 配置先ディレクトリを作成
4. 画像ファイルをコピー
5. works レコードを作成
6. move モードの場合、元ファイルを削除
7. エラー時: コピー先ディレクトリを削除してロールバック

### サムネイル生成

フォルダ内の最初の画像から WebP 形式でサムネイルを生成する。

- 最大サイズ: 200x280px
- 品質: 65

---

## 6. インポートバナー

画面下部に表示される進捗通知。インポートの状態遷移に応じて表示内容が変わる。

### 状態遷移と表示

| 状態         | 表示内容                      |
| ------------ | ----------------------------- |
| キューに追加 | ジョブ ID 発行                |
| 処理開始     | 「取り込み中...」             |
| 進捗         | 「N/M」で現在の処理位置を表示 |
| 完了         | 「成功 N 件 / 失敗 M 件」     |

### クローズ動作

- **エラーなし**: 設定に応じて自動クローズ（0 / 1 / 3 / 5 秒）。0 は自動クローズなし
- **エラーあり**: 手動クローズのみ。エラー詳細をリスト表示

---

## 7. 対応画像形式

jpg, jpeg, png, gif, webp, bmp（大文字小文字不問）

---

## 8. 現状の制約

- **ディレクトリ単位のみ**: インポート対象はディレクトリのみ。単体の画像ファイルをドロップした場合は親ディレクトリのインポートとして処理される（Issue #164 で単体画像対応を予定）
- **作品種別の固定**: works.type は常に `folder` で登録される
- **一括取り込みのメタデータ制限**: 一括取り込みでは year, genre, circle, origin のメタデータを入力できない（Issue #93）
