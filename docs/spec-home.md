# Sharaku 仕様書 - Home

## 1. 役割

Home は、何を見るかまだ決めていないときに、コレクションから候補を出す画面。ライブラリがあるときの起動直後・ライブラリ切り替え後の表示先になる。探したいものが決まっているときは、ナビの「ブラウズ」（作品グリッド。[ライブラリ管理・設定](spec-library-management.md) の 4 章）を使う。

## 2. 画面構成

上から順に並ぶ。

1. **おまかせで見る**: ランダムに選んだ作品をビューアで開く。選んだ並びがそのまま ←/→ の送り順になる
2. **続きから**: 最後に閲覧した作品と、閉じたときのページ。「N 枚目から再開」（2 ページ目以降で閉じたときだけ）と「最初から」でビューアに入る
3. **棚**: 横スクロールのカード列を縦に積む。作品が 1 件もない棚は表示しない

作品が 1 件もないライブラリでは、取り込みを促す案内だけを表示する。

## 3. 棚

| 棚             | ルール                                            | カードの補足    | バッジ              |
| -------------- | ------------------------------------------------- | --------------- | ------------------- |
| 最近見た       | 閲覧した作品を最終閲覧日時の新しい順              | 最終閲覧        | なし                |
| ピックアップ   | 2 回以上閲覧し、14 日以上開いていない作品を古い順 | 前の閲覧回数    | 「Nか月ぶり」       |
| 最近追加した   | 全作品を登録日時の新しい順                        | 追加日          | なし                |
| よく見ている   | 閲覧した作品を閲覧回数の多い順                    | 閲覧回数        | 上位 3 件に「No.N」 |
| まだ見ていない | 一度も閲覧していない作品を登録日時の新しい順      | 追加日          | 「未読」            |
| ランダム       | 全作品から無作為に選ぶ。「引き直す」で選び直す    | 最終閲覧 / 未読 | なし                |

- 各棚は最大 20 件
- カードは表紙（3:4）・右下に枚数・タイトル・補足 1 行
- カードを選ぶと、その棚の並びを送り順にしてビューアで開く。ビューアを閉じると Home に戻る
- 「すべて再生」は棚の先頭の作品から、棚の並びを送り順にしてビューアで開く
- 「すべて見る」はブラウズに移る（棚ごとの絞り込みは Browse の刷新（#356）で扱う）
- ピックアップのルールは仮の単純なもので、再発見のスコアリング（#355）で置き換える

### 棚の足し方

棚の定義は `src/lib/shelves.ts` の `SHELVES` に一か所でまとめている。各棚は、中身を返すバックエンドのコマンド（SQL は `src-tauri/src/history.rs`）と、カードの補足・バッジの出し方を持つ。棚を足すときは、履歴クエリとコマンドを足して `SHELVES` に 1 件加える。Home 本体は変えなくてよい。

## 4. 見た目

色は `src/app.css` の `--sk-*` トークンにまとめている。ダークテーマでは暗い地に朱（`#E4693F`）の差し色、ライトテーマでは同じ差し色の明るい地になり、既存のテーマ切り替えに従う。フォントは Web フォントを読み込まず、日本語のシステムフォントを使う。
