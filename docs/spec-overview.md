# Sharaku 仕様書 - 全体概要

## 1. アプリ概要

Sharaku はローカルの画像フォルダを「作品」として管理・閲覧するデスクトップアプリケーション。

ユーザーは「ライブラリ」を作成し、その中にフォルダを作品として登録する。登録した作品はグリッド形式で一覧表示され、ビューアでページ送りしながら閲覧できる。作品にはタグを付与してフィルタリングできる。

---

## 2. 主要な概念

### ライブラリ

作品を束ねる最上位の管理単位。複数のライブラリを作成でき、同時にアクティブにできるのは 1 つだけ。ライブラリごとにリソース管理モード（full / metadata_only）や設定が独立している。

### 作品

ライブラリに属する個々の管理単位。「フォルダ＝作品」（フォルダ内の画像がページとして扱われる）に加え、単体の画像ファイルを 1 ページの作品として登録することもできる。作品にはタイトル、作者、年、ジャンル、サークル、出典の 6 つのメタデータを持たせることができる。

DB スキーマ上は作品種別として `image`, `pdf`, `archive`, `folder` の 4 種が定義されているが、実装上は `folder` と `image` のみ使用している。

### タグ

作品に付与する分類ラベル。ライブラリごとに管理され、名前とカテゴリ（任意）を持つ。作品とタグは多対多の関係。

### プレイリスト

作品を任意の順序でまとめるライブラリごとの管理単位。サイドバーから新規作成・リネーム・削除（確認ダイアログあり）ができ、作品は右クリックメニューから追加、プレイリスト画面から個別に削除できる。追加済みの作品はドラッグ＆ドロップ（ポインタ操作・キーボード操作双方に対応）で並び替えられる。プレイリストからの作品閲覧は、プレイリスト内の並び順でページ送りされる。

---

## 3. 現状の制約

- **作品種別の制限**: 現在 `folder`（フォルダ）と `image`（単体画像）を実装。PDF（`pdf`）、アーカイブ（`archive`）は未対応
