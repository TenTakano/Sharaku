# Sharaku 仕様書 - ビューア機能

## 1. 概要

作品の画像を1ページずつ閲覧する全画面表示のビューア。
ライブラリ画面またはプレイリスト画面で作品をクリックすると開く。

## 2. 画像配信

カスタムプロトコル `sharaku://localhost/view/{workId}/{pageIndex}` を使用する。

Tauri のプロトコルハンドラが URI を解析し、Rust 側で画像データを読み込んでバイナリレスポンスとして返す。

### 作品タイプ別の挙動

- **folder 型**: フォルダ内の画像ファイルを自然順（natord）でソートし、pageIndex 番目の画像を返す
- **非 folder 型**（image 型、および将来の pdf, archive 型）: path に指定されたファイルを直接読み込む。pageIndex=0 のみ有効

### Content-Type

拡張子から判定する（jpg → image/jpeg, png → image/png 等）。

## 3. ページナビゲーション

### 基本操作

- 左右矢印キーまたは画面端のボタンでページ送り

### 作品間の自動遷移

ページ範囲外に到達した場合、ビューアの起動元（ライブラリ画面またはプレイリスト画面）で読み込まれた作品IDリスト内の前後の作品に自動遷移する。プレイリストから開いた場合は、プレイリスト内の並び順で遷移する。

- 次の作品へ遷移 → 先頭ページを表示
- 前の作品へ遷移 → 最終ページを表示

### ループ設定

`l` キーで切り替える。

- ON: 最後の作品の最終ページから最初の作品の先頭ページに戻る（逆方向も同様）
- OFF: リストの端で停止

## 4. 表示モード

### フィットモード

| キー | モード | 説明                                           |
| ---- | ------ | ---------------------------------------------- |
| s    | screen | 画像全体がビューポート内に収まるように縮小表示 |
| w    | width  | ビューポートの幅に合わせて表示                 |
| h    | height | ビューポートの高さに合わせて表示               |

### ズーム

- 範囲: 0.25x 〜 4x
- `+` / `-` キーで 0.25 刻みで変更
- Ctrl/Cmd + マウスホイールで 0.1 刻みで変更
- `0` キーでフィットモードにリセット

## 5. スライドショー

### 操作

スペースキーで再生/停止を切り替える。

### 間隔

1〜999秒（デフォルト5秒）。

### モード

| モード | 説明                                         |
| ------ | -------------------------------------------- |
| page   | ページ単位で進行                             |
| work   | 作品単位でスキップ（次の作品の先頭ページへ） |

### ループ設定との連動

最後に到達した場合:

- ループ ON → 先頭に戻って継続
- ループ OFF → 停止

## 6. フルスクリーン

- `f` キーで切り替え
- フルスクリーン中はコントロールパネルが3秒後に自動非表示になり、マウス移動で再表示される
- Escape キーの挙動:
  - フルスクリーン中 → フルスクリーン解除
  - 非フルスクリーン時 → ビューアの起動元（ライブラリ画面またはプレイリスト画面）に戻る

## 7. タグ管理

- ビューア内でタグの追加・除去が可能
- タグ入力欄で既存タグをサジェストし、未登録の名前で新規作成できる
- タグの除去時は確認ダイアログを表示する

## 8. メタデータ編集

編集ダイアログで以下の6項目を更新できる。

| 項目   | 備考           |
| ------ | -------------- |
| title  | 必須（空不可） |
| artist |                |
| year   |                |
| genre  |                |
| circle |                |
| origin |                |

workType と path は編集不可。

## 9. キーボードショートカット

| キー             | 動作                                    |
| ---------------- | --------------------------------------- |
| ← / →            | ページ送り                              |
| Space            | スライドショー再生/停止                 |
| s                | フィットモード: screen                  |
| w                | フィットモード: width                   |
| h                | フィットモード: height                  |
| + / -            | ズームイン/アウト（0.25刻み）           |
| 0                | ズームリセット                          |
| f                | フルスクリーン切り替え                  |
| l                | ループ切り替え                          |
| Escape           | フルスクリーン解除 / 起動元の画面に戻る |
| Ctrl/Cmd + Wheel | ズーム（0.1刻み）                       |

## 10. 閲覧履歴

ビューアの開閉に合わせて閲覧セッションを自動で記録する。ユーザーの操作は増やさない。

### セッションの区切り

- 作品を表示した時点でセッションを開始する（1作品につき1セッション）
- ビューアを閉じたとき、または前後の作品へ遷移したときにセッションを終了する
- ページを移るたびに、そのセッションの最後のページを更新する。ビューアを閉じずにアプリを終了した場合も、最後に表示していたページは残る（終了時刻は空のまま）

誤操作による開封も現状は1回の閲覧として数える。意味のある閲覧の判定は、記録済みの開始/終了時刻とページから後で導出できる。

### 記録する項目

| 項目         | 説明                                         |
| ------------ | -------------------------------------------- |
| 作品         | 閲覧した作品（作品削除時はセッションも削除） |
| 開始時刻     | セッション開始時刻                           |
| 終了時刻     | セッション終了時刻。未終了なら空             |
| 最後のページ | セッション中に最後に表示していたページ       |

### 履歴クエリ

最終閲覧日時・閲覧回数・総閲覧時間・最後のページは、セッションからクエリ時に導出する。

| コマンド                       | 内容                                                   |
| ------------------------------ | ------------------------------------------------------ |
| `list_recently_viewed_works`   | 閲覧済み作品を最終閲覧日時の新しい順に返す             |
| `list_unviewed_works`          | 一度も閲覧していない作品を登録日時の新しい順に返す     |
| `list_frequently_viewed_works` | 閲覧済み作品を閲覧回数の多い順（同数は新しい順）に返す |
| `get_work_history`             | 作品ごとの最終閲覧日時・閲覧回数・最後のページを返す   |

- 最終閲覧日時はセッションの終了時刻（未終了なら開始時刻）の最新値
- 総閲覧時間は終了済みセッションの合計で、未終了のセッションは0秒として扱う
- 最後のページは最新のセッションのもので、Home の「続きから」に使う

## 11. 現状の制約

- 画像配信の非 folder 型経路は image 型作品のインポート・閲覧で使用される。pdf, archive 型は未実装のため対応する経路は現状未使用
