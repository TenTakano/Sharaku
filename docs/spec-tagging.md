# タグ機能 仕様書

## 1. データモデル

タグはライブラリに所属する。異なるライブラリ間でタグは共有されない。

各タグは以下の属性を持つ:

| 属性     | 必須   | 説明               |
| -------- | ------ | ------------------ |
| name     | はい   | タグの名前         |
| category | いいえ | タグの分類カテゴリ |

ライブラリ内では name と category の組み合わせで一意となる。同じ name でも category が異なれば別のタグとして扱う。

作品とタグは多対多の関係を持ち、中間テーブルで関連付けられる。

### 削除時の振る舞い

- 作品を削除すると、その作品に紐づくタグ関連レコードも CASCADE で自動削除される
- タグを削除すると、そのタグに紐づく作品との関連レコードも CASCADE で自動削除される

いずれの場合も、関連先の実体（作品やタグそのもの）は削除されない。

## 2. タグの CRUD

### 作成

name（必須）と category（任意）を指定してタグを作成する。

### 更新

既存タグの name および category を変更できる。

### 削除

削除操作には確認ダイアログを表示する。確認後、タグ本体と作品との関連レコードが CASCADE で削除される。

### 検索

name に対する部分一致（LIKE）検索を行う。前方一致ではなく、名前の途中にマッチする文字列でもヒットする。検索結果は最大50件に制限される。

## 3. タグの付与・除去

### 付与

ビューア画面のタグ入力欄からタグを付与する。

- 入力中は既存タグがサジェストされる（部分一致検索）
- 既存タグを選択するとその作品に付与される
- 未登録の名前を入力した場合、新規タグとして作成したうえで付与される

### 除去

作品に付いているタグはバッジとして表示される。バッジをクリックすると確認ダイアログが表示され、承認するとタグの紐づけが解除される。タグ自体は削除されない。

## 4. タグによるフィルタリング

### フィルタの操作方法

タグフィルタは以下の2箇所から操作できる:

- **ツールバー**: ライブラリ画面上部のタグ入力欄から選択
- **サイドバー**: タグツリーのタグをクリックして追加/解除

タグを選択すると、そのタグを持つ作品のみが表示される。同じタグを再度選択するとフィルタが解除される。

### 複数タグ選択時の検索モード

タグを2つ以上選択すると、検索モードの切り替えボタンが表示される。

| モード | 動作                                   |
| ------ | -------------------------------------- |
| AND    | 選択した全てのタグを持つ作品のみ表示   |
| OR     | 選択したいずれかのタグを持つ作品を表示 |

## 5. サイドバーのタグツリー

サイドバーにはライブラリ内のタグがカテゴリ別にグループ化されて表示される。

### 表示ルール

- カテゴリが設定されているタグは、そのカテゴリ名のグループに表示される
- カテゴリが未設定のタグは "other" グループに表示される
- 各カテゴリは折りたたみ/展開が可能

### フィルタ連動

- 現在フィルタ中のタグはハイライト表示される
- タグをクリックするとフィルタに追加/解除される
- ライブラリ画面以外の画面からタグをクリックした場合は、ライブラリ画面に遷移してからフィルタが適用される

## 6. 現状の制約

- **一括付与非対応**: 複数作品に同時にタグを付ける操作には対応していない
- **インポート時のタグ指定非対応**: 作品のインポート時にタグを指定する機能はない
